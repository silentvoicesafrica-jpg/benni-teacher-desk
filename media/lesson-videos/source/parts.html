The System Unit

The box that holds the main parts of the computer.

Inside is the memory where work is kept.

Look at the box in your class. Point to the power light.

INPUT: Tell the computer

🖱️Mouse
⌨️Keyboard
🕹️Joystick

Input = you send information in to the computer.

Input devices: mouse, keyboard, joystick, light pen, microphone.

OUTPUT: The computer tells you

🖥️Monitor
🖨️Printer
🔊Speakers

Output = the computer shows or gives information out to you.

Quick memory trick: Input goes in. Output comes out.

RAM and ROM

RAM

Temporary working desk.
Lost when the power goes off.

ROM

Permanent instruction book.
Stays when the power goes off.

Ask yourself: is it a working desk, or a book that stays?
