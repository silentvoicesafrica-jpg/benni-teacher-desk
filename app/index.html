CLOUD BACKUP

Your work stays local, with an encrypted copy in Google Drive.

The app works offline first. When Google Drive for desktop is running, choose a synchronized folder and save an encrypted backup there. The app never uploads learner records or passwords as readable files.

Local-first
RECOMMENDED PATH

Google Drive encrypted backup

☁

Install Google Drive for desktop on Windows and add a folder such as Eddy_Teacher_Assistant_Backups to Drive sync. The app writes a password-protected backup file into that folder; Google Drive then synchronizes it.

  1. Install and sign in to Google Drive for desktop.
  2. Choose or create a private Drive-synchronized backup folder.
  3. Use the button below to choose that folder in this browser.
  4. Save an encrypted backup after important work and keep one occasional external-drive copy.
BACKUP HEALTH

Know when you are protected

No cloud backup yet

The warning becomes active when no encrypted cloud backup has been saved in the last 7 days. This is a reminder, not a claim that your local work is lost.

Do not enter Google passwords here. Sign in through Google Drive for desktop or the browser folder chooser only.

Privacy ruleKeep learner names, medical information, passwords, and other sensitive data out of ordinary cloud documents. The app backup is encrypted, but your backup password must be kept safely.
How this worksGoogle Drive is the cloud copy. The laptop and phone do not need an external hard drive connected during normal use. An external drive is only an occasional second backup, and the app remains usable when offline.
